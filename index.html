🎉 GitHub Pages 公開ステップ

  1. このファイルを git commit & git push で GitHub にプッシュします。
  2. リポジトリの Settings > Pages にアクセスします。
  3. Build and deployment > Source で Deploy from a branch を選択します。
  4. Branch で main ブランチの / (root) を選んで Save をクリックします。
  5. 数十秒〜数分でページが公開されます！
